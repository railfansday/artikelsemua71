Latest Update: Block-sparse GPU kernels

🌐 Source: Openai • 📅 06 Dec 2017 • ⏱️ 1 min read (61 words, ⚡ Quick Read)

It has been revealed that we’re releasing highly-optimized GPU kernels for an underexplored class of neural network architectures: networks with block-sparse weights. Depending on the chosen sparsity, these kernels can run orders of magnitude faster than cuBLAS or cuSPARSE. We’ve used them to attain state-of-the-art results in text sentiment analysis and generative modeling of text and images.
