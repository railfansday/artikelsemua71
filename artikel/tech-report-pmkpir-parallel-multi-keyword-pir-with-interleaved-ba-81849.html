Tech Report: PMKPIR: Parallel Multi-Keyword PIR with Interleaved Batching for Private Boolean Retrieval

🌐 Source: Arxiv • 📅 19 Nov 2026 • ⏱️ 1 min read (223 words, 📖 Standard)

Industry observers note that arXiv:2611.24248v1 Announce Type: latest Abstract: Keyword Private Information Retrieval (Keyword PIR) allows consumers to retrieve data associated with specific keywords from a database while protecting query privacy. However, existing Keyword PIR schemes supporting boolean retrieval either incur high computational overhead due to multiple database traversals, or fail to support universal boolean computation. We propose PMKPIR, a novel keyword PIR scheme supporting both parallel multi-keyword queries and universal boolean computation. We utilize the single instruction multiple data (SIMD) capability of BFV homomorphic encryption to propose an interleaved batching method, and design IBPIR based on this method, achieving the private matching of multiple keywords in a single database traversal. Furthermore, we design a boolean query processing method, extending the parallel capability of interleaved batching from keyword querying to boolean query computation, to support universal boolean computation and accelerate boolean operations. Building upon IBPIR, we integrate this method to further design PMKPIR. To the best of our knowledge, PMKPIR is the first Keyword PIR scheme to support multi-keyword batch matching within boolean queries. Security analysis demonstrates that, consistent with existing PIR schemes supporting boolean retrieval, PMKPIR preserves the core security guarantees of classic PIR. Compared with state-of-the-art schemes, PMKPIR reduces query time, communication overhead, storage overhead, and peak memory by up to 79.06%, 75.00%, 97.92%, and 80.26%, respectively.
