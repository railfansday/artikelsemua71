Training for sustainable scientific software in the AI era: from code production to scientific stewardship

🌐 Source: Arxiv • 📅 19 Nov 2026 • ⏱️ 1 min read (191 words, 📖 Standard)

It has been revealed that arXiv:2611.23330v1 Announce Type: newly introduced Abstract: Generative and agentic artificial intelligence (AI) systems are changing how researchers interact with scientific software. Their effects on productivity vary across tasks and people, but they can weaken the connection between producing a successful computational artifact and retaining scientific command over the consequential choices and evidence on which it depends. For high-energy physics, this shifts part of the training challenge from code production toward scientific stewardship: researchers must be able to validate, explain, reproduce, maintain, and justify software and workflows partly generated or modified by AI. We argue that AI-aware software training should therefore combine dedicated instruction on AI systems with the integration of AI into established software and analysis training. Testing, provenance, reproducibility, resource judgment, and scientific validation should be exercised in AI-assisted workflows, with competence judged by the evidence supporting a result rather than by code generation alone. We frame this as a problem of sustainable scientific software: AI-assisted workflows should remain trustworthy and maintainable, use computational resources responsibly, and avoid making core competence unnecessarily dependent on privileged access to particular tools or infrastructure.
